MirrorLock is a native macOS menu bar app for botsitting — leave Claude Code, Cursor, Copilot, or any AI coding agent running while you step away. Your desktop stays fully visible under a high-performance live mirror overlay while keyboard, mouse, and trackpad are hard-locked. Unlock instantly with Touch ID or Apple Watch.

Apple Watch & Touch ID

Rest your finger on Touch ID or double-press your Apple Watch side button. Optional "Tap to unlock with watch".

☕

Keeps Mac Awake

Active power assertions prevent display and system sleep so running agents finish their tasks without disruption.

⏱️

Auto-Lock When Idle

Optionally locks after 1–30 min inactivity, with an interactive 10-second cancelable countdown HUD.

🔒

Hard Input Lock

Keyboard, mouse, trackpad, scrolling, gestures, and media keys are blocked at the macOS event-tap level.

🖥️

Multi-Display Safe

Secondary displays are blacked out while locked. Plugging or unplugging monitors never unlocks your Mac.

How it works

  1. 1

    Launch MirrorLock

    It lives quietly in your menu bar. Grant Screen Recording, Accessibility, and Input Monitoring permissions.

  2. 2

    Press ⌘⇧M to lock

    The live desktop mirror activates instantly — coworkers can see progress, but cannot touch anything.

  3. 3

    Walk away & botsit

    Your Mac stays awake, long-running agent builds carry on, and intruder touches trigger alert flashes.

  4. 4

    Touch ID or Apple Watch

    Return, tap your sensor or double-press your Apple Watch, and you're immediately back in control.

Install via Homebrew

The cleanest way to install on macOS — direct from our official tap:

brew tap shubhransh-gupta/tap
brew install --cask mirrorlock

Or install via one-line curl:

curl -fsSL https://raw.githubusercontent.com/shubhransh-gupta/mirrorLock/main/scripts/install.sh | bash
